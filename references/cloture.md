# Clôture de campagne — `$dev cloture <campagne>`

Portée : une campagne entière, quand toutes ses issues sont closes ou explicitement
mises de côté.

1. Vérifier les preuves : chaque issue close a sa PR fusionnée et son bilan versé.
2. Bilan de campagne dans Obsidian (sous-agent `obsidian`, `ingestion.md`) :
   résultat, décisions prises seul (journal), écarts au contrat, suites.
3. `pilote.mjs campagne cloturer <nom>` : statut `close`, registre archivé dans
   `.pilote/archives/`.
4. Titre du chat de campagne suffixé `✅` ; le nettoyeur l'archivera après 7 jours.
5. Chat `📘 BILAN` dans `04 Relais & maintenance` seulement si Paul le demande.
